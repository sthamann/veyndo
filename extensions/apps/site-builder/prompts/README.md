# Shop design prompts

`site-design.v1.txt` is the app-owned system prompt for native reference-guided
alternatives. Its immutable ID is `site-design@1`; `manifest.json` binds its digest.
The shared inference registry adds that ID/hash to ordinary usage evidence.
Prompt governance checks host and app owners, duplicate IDs, file digests and
unchanged published revisions when `PROMPT_BASE` is provided.

Style-only output supplies a bounded empty content document and a theme. The host
retains the saved page content/structure and validates the ordinary native proposal.
References and uploaded images remain untrusted evidence. Registered visual workspace
fixtures exercise image transport, denied content changes, selected sections,
invalid references, native review and stale revision rejection. Actual model/browser
acceptance is recorded separately in the handbook.
